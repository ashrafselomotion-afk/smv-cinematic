Connect to the site

This page edits the film and photography list, then commits it to the website repository. It runs entirely in your browser — your token is never sent anywhere except GitHub.

  1. Open github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Under Repository access choose Only select repositories and pick smv-cinematic.
  3. Under Permissions → Repository permissions set Contents to Read and write. Nothing else is needed.
  4. Give it an expiry date, generate it, and paste it below.

Treat the token like a password. It can change anything in that repository. Set an expiry date, and if you use a shared computer leave “Keep me signed in” unticked. You can revoke it at any time from the same GitHub settings page.

Films

Featured films appear on the homepage, in the numbered list. Tick up to five. A film with a preview loop plays by itself in the grid instead of showing a still — upload a short, silent clip and it takes over automatically.

Photography

Photos are resized to 1600px and re-encoded before upload, so a 12MB camera file lands as a few hundred kilobytes. Description is required — it is what a screen reader announces, and the site is built to stay accessible.

Before you publish anyone recognisable: confirm you hold consent, and that the client has approved the set. Nothing here checks that for you.

No photography yet. The website shows an honest “archive is being prepared” message until you add some.

Clients

This is the moving strip under the homepage hero. Each organisation shows as a typeset name unless you supply a real logo file — we never draw an approximation of somebody else’s trademark.

Before you add a name: be sure it is genuinely a credit of yours, and that the organisation permits being listed. Showing their logo is a separate permission again — UAE government entities in particular tend to restrict who may reproduce their mark.
